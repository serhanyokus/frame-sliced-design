# Format: talking-head

A person speaks to camera, supported by app screens and visual emphasis.

**Raw material:** camera footage. The [shooting steps](../../workflow/shoot.md), hiding cuts, and color matching are specific to this format.

## Segments
1. **Hook (0–3 sec):** a visual hook block → [hook](../../blocks/hook/README.md)
2. **Introduction:** who and what
3. **Main content:** 2–4 benefits or ideas; at most one screen moment or one emphasis per point
4. **Closing line:** the spoken portion ends here
5. **Outro (1.5–2 sec):** a silent end card → [outro](../../blocks/outro/README.md)

## Fixed and variable
- Fixed: brand tokens, caption style, outro structure; add a series tag if this is part of a series
- Variable: hook type, emphasis types, screen selection, transition type, music, and timing

## Blocks and techniques used

Hook, screen moment, outro · captions, emphasis, motion, transitions, sound design, color matching.
