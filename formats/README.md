# formats (pages layer)

> The talking-head format is the only one fully specified so far. Document other formats from the actual steps used when their first videos are made.

Each video type is a format. Its format bible describes its segments, what stays fixed, what can vary, and which blocks and techniques it uses.

- [talking-head](talking-head/README.md): a person speaking to camera
- [screen-demo](screen-demo/README.md): a demo focused on app screens
- [motion](motion/README.md): an animated or motion-graphics video
