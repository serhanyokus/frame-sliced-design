# Start here

Understand Frame-Sliced Design in five minutes:

1. **The rules stay stable; each video can change.** `rules/` applies to every video, but a new video does not have to look like the last one. Brand and series identity are the consistent parts.
2. **Resolve conflicts by priority.** When two decisions conflict, the [decision hierarchy](../rules/decision-priority.md) tells you what wins.
3. **Plan the video before rendering.** Approve the script, paper edit, and visual plan before you render.
4. **Choose from a library instead of inventing every piece from scratch.** Select techniques and blocks to fit the story, then combine them.
5. **Learn from every release.** Record performance in `learning/` and usage in `brands/<brand>/series/<series>/log.md`.
