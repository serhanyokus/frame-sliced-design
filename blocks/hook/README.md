# Block: hook

The first 1–3 seconds. It catches the eye immediately and supports the spoken line.

## Types (library)

| Type | What it does | Status |
|---|---|---|
| kinetic-labels | Spoken words arrive as angled labels, followed by a stamp | Used |
| big-question | One question fills the screen | _Not yet used_ |
| counter | Opens with a counter or number | _Not yet used_ |
| screen-first | Opens on an app screen, then brings in the speaker | _Not yet used_ |

## Rule

Do not use the same hook type in two consecutive videos in a series. Check `log.md`.

## Techniques used

Emphasis, motion (opening punch-in), and sound design (pop, bell).
