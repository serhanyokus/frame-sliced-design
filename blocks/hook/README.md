# Block: hook

İlk 1–3 saniye. Görsel olarak hemen yakalar; konuşma metnini taşır.

## Tipler (kütüphane)
| Tip | Ne | Örnek |
|---|---|---|
| kinetic-labels | Konuşma metni, söylendikçe eğik etiketler hâlinde gelir; sonunda mühür | Rota Gün 1 |
| big-question | Ekranı kaplayan tek bir soru | _henüz kullanılmadı_ |
| counter | Sayaç/sayı ile açılış | _henüz kullanılmadı_ |
| screen-first | Uygulama ekranıyla açılış, kişi sonra girer | _henüz kullanılmadı_ |

## Kural
Aynı serideki iki ardışık videoda aynı hook tipi kullanılmaz (`log.md`'den kontrol).

## Kullandığı teknikler
emphasis, motion (açılış punch-in'i), sound-design (pop, çan)
