# Block: outro

Konuşma bittikten sonra gelen 1,5–2 sn'lik sessiz kapanış kartı. Sesli "bizi takip et" kullanılmaz.

## Yapı
- Marka renginde tam ekran kart (daire açılışıyla gelir)
- Ana satır: serinin devamı (ör. "Gün 2'de görüşürüz")
- Küçük etiket: eylem (ör. "takip et")
- Alt: marka adı + kanal (ör. App Store)
- Ses: swoosh + kısa çan

## Değişken
Ana satır her videoda konuya göre değişebilir ("Gün 3'te koçu anlatıyorum").
