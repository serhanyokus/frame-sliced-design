# Block: outro

A silent 1.5–2 second end card after the speech ends. Do not add a spoken “follow us.”

## Structure
- Full-screen card in the brand color, revealed with a circular opening
- Main line: a continuation of the series (for example, “See you on Day 2”)
- Small label: an action (for example, “Follow”)
- Bottom line: brand name + channel (for example, App Store)
- Sound: swoosh + short bell

## Variable

The main line can change to fit each video's topic (for example, “On Day 3, I’ll show you the coach”).
