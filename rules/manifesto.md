# Manifesto

**Always**
- The story makes sense with the sound off.
- The first second has a visual hook.
- Every visible action has a sound (a tap gets a click; paper gets a paper sound).
- Consider a short pause or a gap in the music before an important sentence.
- Propose a new element before adding it.
- Do not save files to a permanent folder before final approval.

**Never**
- Show captions, a large headline, and a dense screen at the same time.
- Cover the face with text.
- Use unlicensed music.
- Show a screen that cannot be read; enlarge it or leave it out.
- Add an effect to every cut.
