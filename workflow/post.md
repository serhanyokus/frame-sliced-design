# Post-production

Order matters; each step builds on the previous one.

1. **Audio edit:** use the selected takes, preserve breaths, and do not clip word endings → [sound design](../techniques/sound-design/README.md)
2. **Audio cleanup:** light noise reduction, compression, −16 LUFS
3. **Picture edit:** sync to audio, frame accurate
4. **Color matching:** correct lighting differences between takes → [color matching](../techniques/color-match/README.md)
5. **Screens and blocks:** follow the visual plan → [blocks](../blocks/README.md)
6. **Text:** hook, captions, emphasis → [captions](../techniques/captions/README.md), [emphasis](../techniques/emphasis/README.md)
7. **Motion:** zoom, hiding cuts, transitions → [motion](../techniques/motion/README.md), [transitions](../techniques/transitions/README.md)
8. **Music and effects** → [sound design](../techniques/sound-design/README.md)
9. **Outro** → [outro](../blocks/outro/README.md)
