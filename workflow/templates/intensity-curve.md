# Template: intensity curve

Based on Bruce Block's contrast and affinity principle. Map the video's energy and place emphasis at the peaks.

```text
intensity
  5 |  ●                         ●
  4 |  ●           ●             ●
  3 |  ●     ●     ●       ●     ●         ●
  2 |  ●  ●  ●  ●  ●  ●    ●  ●  ●  ●   ●  ●
  1 |__●__●__●__●__●__●____●__●__●__●___●__●___
      hook  intro  benefit 1  benefit 2  close
```

| Section | Time | Intensity (1–5) | What it creates | Emphasis type |
|---|---|---|---|---|
| Hook | | 5 | | |
| Intro | | 2 | | — |
| Benefit 1 | | | | |
| Benefit 2 | | | | |
| Close | | | | outro |

## Rules
- Leave space between peaks; a video that stays at 5 throughout is exhausting.
- Do not use the same emphasis type at two peaks (contrast).
- Let the close settle; the outro should stand on its own.
