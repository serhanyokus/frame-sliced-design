# Şablon: yoğunluk eğrisi

Bruce Block'un kontrast/uyum ilkesinden. Videonun enerji grafiği; vurgular zirvelere yerleşir.

```
yoğunluk
  5 |  ●                         ●
  4 |  ●           ●             ●
  3 |  ●     ●     ●       ●     ●         ●
  2 |  ●  ●  ●  ●  ●  ●    ●  ●  ●  ●   ●  ●
  1 |__●__●__●__●__●__●____●__●__●__●___●__●___
      hook  tanıtım  fayda 1   fayda 2   kapanış
```

| Bölüm | Zaman | Yoğunluk (1–5) | Ne yaratıyor | Vurgu tipi |
|---|---|---|---|---|
| Hook | | 5 | | |
| Tanıtım | | 2 | | — |
| Fayda 1 | | | | |
| Fayda 2 | | | | |
| Kapanış | | | | outro |

## Kurallar
- Zirveler arasında iniş olmalı; sürekli 5 olan video yorar.
- Aynı vurgu tipi iki zirvede kullanılmaz (kontrast).
- Kapanış sakin; outro tek başına durur.
