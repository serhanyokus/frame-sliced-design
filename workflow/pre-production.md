# Pre-production

1. **One-sentence message:** If this video tells the viewer one thing, what is it?
2. **Short script:** The spoken text. Keep it concise and conversational.
3. **Paper edit (after recording):** Transcribe the takes, choose the cleanest take for each sentence, and remove repeated ideas.
4. **Visual plan:** What appears for each sentence? You / screen / emphasis / nothing. Show a screen only when it directly matches what is being said.
5. **Intensity curve:** Map the video's energy (Bruce Block's contrast and affinity). Peak at the hook, ease off for the explanation, rise again for the main benefit, then settle for the close. Place emphasis at peaks.
6. **Series check:** Review `log.md`; do not repeat the hook or emphasis type from the previous video.

✅ Approval: send the edited script, visual-plan table, and intensity curve together.
