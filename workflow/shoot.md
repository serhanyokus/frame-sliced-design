# Shoot

- Record from a short script; even if you improvise, know the sentences in advance.
- Pause for about one second between sentences. If you stumble, repeat the sentence from the beginning.
- Plan a gesture where you will show a screen (for example, point to the upper right); the screen appears in that corner.
- Keep the lighting steady throughout; if possible, record all takes in one session.
- Add to the b-roll library when there is an opportunity: capture 3–5 second close-ups (tapping a phone, opening a notebook).
