# brands (entities layer)

Brand-specific material belongs here. Copy `_template` to start a brand pack. A brand pack can live privately in its own project; this repository defines its structure only.

Each brand pack contains:
- `brand.md`: voice, naming, and restrictions
- `tokens.json`: colors and type (overrides foundation defaults)
- `screens/`: real product screens
- `videos/`: one-off videos, each in its own folder (`edit.json`, `timeline.json`, `exports/`)
- `series/` (optional): series, each with a `bible.md`, `log.md`, and episode folders

A video does not have to belong to a series. One-off videos have no series tag or “next episode” outro.

Setup guide: [set up a brand pack](../start/brand-pack.md)
