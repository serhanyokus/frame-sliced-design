# Technique: transitions

Use transitions only between sections or where different takes join. Do not add an effect to every cut.

| Type | What it does | Example |
|---|---|---|
| stripe-wipe | Diagonal colored stripes sweep across the screen and cover the cut at its midpoint | Joining two different takes |
| iris | A circle in the brand color closes and opens | Moving between sections |

Pair every transition with a swoosh.
