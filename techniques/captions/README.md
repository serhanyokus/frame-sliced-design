# Technique: captions

- 2–3 kelimelik parçalar; noktalama ve ~16 karakterde bölünür.
- Söylenen kelime marka renginde bir kutu içinde beyaz yazıyla vurgulanır.
- Giriş: hafifçe aşağıdan kayarak (≈0,14 sn), zıplamadan.
- Stil: kalın yazı (Inter ExtraBold ~66 px), koyu kontur.
- Büyük vurgu varken gizlenir; telefon ekranı varken yer değiştirir.
- Zamanlama kelime düzeyinde olmalı (kelime zaman damgası veren bir transkript ile).
