# Technique: sound-design

## Konuşma
- Hafif gürültü azaltma (highpass ~70 Hz + hafif FFT denoise), yumuşak sıkıştırma, −16 LUFS.
- Kesimler sesin söndüğü noktaya kadar uzatılır; kelime sonları yutulmaz.

## Müzik
- Özgün ya da lisanslı. Telifli parça yok.
- Konuşurken ~−36 LUFS, aralarda ~−28 LUFS (otomatik ducking).
- Önemli cümleden önce ~0,3 sn müzik boşluğu.

## Efektler
| Görünen şey | Ses |
|---|---|
| Dokunuş | tık |
| Kart/ekran belirmesi | hafif tık |
| Büyük vurgu, etiket | pop |
| Takvim/kâğıt hareketi | kâğıt sesi |
| Geçiş | swoosh |
| Seri mührü | ışıltılı çan arpeji |
