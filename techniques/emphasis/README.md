# Technique: emphasis

Use emphasis only on key phrases at peaks in the intensity curve. Use a different type for each emphasis in a video.

## Types (library)

| Type | What it looks like | Example use |
|---|---|---|
| big-kinetic | One large word fills the screen and arrives with a slight shake | A single key phrase |
| stacked-chips | Cards slide in from the left one by one (✓ ✕ ↗) | Three short points: what works, what is missing, what is improving |
| sticker | A label sticks to the corner of a screen | Name an on-screen feature in one word |
| page-flip | A card opens like a calendar page | A day or date |
| stamp | A circular seal lands with impact | A series episode number |

## Rules
- Hide captions during emphasis.
- Do not cover the face with emphasis.
- Add every new type to this table.
