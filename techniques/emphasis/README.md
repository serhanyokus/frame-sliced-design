# Technique: emphasis

Sadece anahtar ifadelerde, yoğunluk eğrisinin zirvelerinde. Aynı videoda her vurgu farklı tipte olur.

## Tipler (kütüphane)
| Tip | Ne | İlk kullanım |
|---|---|---|
| big-kinetic | Ekranı kaplayan büyük kelime, hafif sallanarak gelir | Rota Gün 1: "SINIRSIZ SORU" |
| stacked-chips | Sırayla soldan kayan kartlar (✓ ✕ ↗) | Rota Gün 1: "nerede iyisin…" |
| sticker | Bir ekranın köşesine yapışan etiket | Rota Gün 1: "7/24" |
| page-flip | Takvim yaprağı gibi açılan kart | Rota Gün 1: "PAZARTESİ" |
| stamp | Daire mühür, çarparak gelir | Rota Gün 1: "GÜN 1" |

## Kurallar
- Vurgu varken altyazı gizlenir.
- Vurgu yüzü kapatmaz.
- Yeni tip eklenince bu tabloya yazılır.
