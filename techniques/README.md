# techniques (features katmanı)

Tek tek kurgu teknikleri. Her teknik bağımsızdır, sadece `foundation/` ve marka tokenlarını kullanır.

| Teknik | Ne yapar |
|---|---|
| [captions](captions/README.md) | Konuşmayı takip eden altyazı |
| [emphasis](emphasis/README.md) | Önemli yerlerde büyük vurgu (farklı tipler) |
| [motion](motion/README.md) | Yakınlaşma, punch-in, kesim maskeleme, ekran büyütme |
| [transitions](transitions/README.md) | Geometrik geçişler |
| [sound-design](sound-design/README.md) | Ses temizliği, müzik, efektler, sessizlik |
| [color-match](color-match/README.md) | Take'ler arası ışık/renk eşitleme |
