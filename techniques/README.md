# techniques (features layer)

Individual editing techniques. Each technique is independent and uses only `foundation/` and brand tokens.

| Technique | What it does |
|---|---|
| [captions](captions/README.md) | Captions timed to the spoken words |
| [emphasis](emphasis/README.md) | Large visual emphasis on key moments, using varied types |
| [motion](motion/README.md) | Zooms, punch-ins, hiding cuts, and screen enlargements |
| [transitions](transitions/README.md) | Geometric transitions |
| [sound-design](sound-design/README.md) | Audio cleanup, music, effects, and silence |
| [color-match](color-match/README.md) | Matches lighting and color between takes |
