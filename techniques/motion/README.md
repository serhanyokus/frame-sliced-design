# Technique: motion

- **Slow push:** önemli cümlede 1,0 → ~1,07 yavaş yakınlaşma.
- **Punch-in:** vurgu anında hızlı küçük yakınlaşma (~1,10–1,12).
- **Kesim maskeleme:** ardışık parçalarda kadraj dönüşümlü olarak normal / hafif yakın; jump-cut kamera değişimi gibi görünür.
- **Açılış:** ~1,15'ten 0,5 sn'de yerine oturma.
- **Ekran büyütme:** bkz. [blocks/screen-moment](../../blocks/screen-moment/README.md).
- Yakınlaşma merkezi yüz hizası (kare yüksekliğinin ~%34'ü).
