# Sözlük

| Terim | Anlamı |
|---|---|
| Hook | İlk 1–3 saniyede izleyiciyi yakalayan açılış |
| Paper edit / kâğıt kurgu | Çekimleri metin üzerinde kesip sıralama, render'dan önce |
| Take | Aynı cümlenin bir çekimi |
| Hard cut | Efektsiz anlık kesim |
| Jump cut | Aynı kadrajda zaman atlaması; kadraj değişimiyle maskelenir |
| Punch-in | Hızlı, kısa yakınlaşma |
| Slow push | Yavaş, sürekli yakınlaşma |
| J-cut / L-cut | Sesin görüntüden önce / sonra geçmesi |
| Safe zone | Platform arayüzünün kapatmadığı alan |
| Ducking | Konuşma varken müziğin otomatik kısılması |
| Intensity curve / yoğunluk eğrisi | Videonun enerji grafiği (Bruce Block) |
| Contrast / affinity | Kontrast yoğunluğu artırır, uyum düşürür (Bruce Block) |
| Format bible | Bir formatın sabit ve değişkenlerini tanımlayan doküman |
| Pattern interrupt | Dikkati tazeleyen beklenmedik görsel/ses değişimi |
| LUFS | Algılanan ses yüksekliği ölçüsü |
