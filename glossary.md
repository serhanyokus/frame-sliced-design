# Glossary

| Term | Meaning |
|---|---|
| Hook | Opening that catches the viewer in the first 1–3 seconds |
| Paper edit | Selecting and ordering footage as text before rendering |
| Take | One recording of the same line |
| Hard cut | An immediate cut with no effect |
| Jump cut | A time skip in the same framing, concealed by changing the framing |
| Punch-in | A quick, brief zoom-in |
| Slow push | A slow, continuous zoom-in |
| J-cut / L-cut | Audio moves to the next shot before / after the picture does |
| Safe zone | An area not covered by the platform interface |
| Ducking | Automatic lowering of music while someone is speaking |
| Intensity curve | A graph of the video's energy (Bruce Block) |
| Contrast / affinity | Contrast increases intensity; affinity lowers it (Bruce Block) |
| Format bible | A document defining a format's fixed and variable parts |
| Pattern interrupt | An unexpected change in image or sound that refreshes attention |
| LUFS | A measure of perceived loudness |
